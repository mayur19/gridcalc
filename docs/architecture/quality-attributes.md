# Quality attributes

Each attribute below has measurable targets and a named verification. Verification is one of:

- **Test**: an automated test that exists today (file path given) and runs in CI.
- **CI step**: a step in `.github/workflows/ci.yml` (`lint`, `format:check`, `typecheck`,
  `test:coverage`, `build`).
- **Planned**: a ticket that will add the measurement. Most latency targets are in this group
  until the performance harness (GC-102) and metrics endpoint (GC-101) exist. A target with only
  a planned verification is a design budget, not a measured fact.

Reference hardware for latency targets: one API process on 2 vCPU / 4 GB RAM, PostgreSQL 15 on
the same host, warm OS cache.

## 6. Scalability limits (explicit, enforced)

| Limit                        | Value                           | Where                                                             |
| ---------------------------- | ------------------------------- | ----------------------------------------------------------------- |
| Edits per PATCH              | 1,000                           | `MAX_EDITS_PER_REQUEST`, `packages/shared/src/api/schemas.ts`     |
| Non-empty cells per workbook | 200,000 (configurable)          | `MAX_CELLS_PER_WORKBOOK`, 413 `PAYLOAD_TOO_LARGE`                 |
| Characters per cell          | 8,192                           | `MAX_RAW_LENGTH`, and `cells.raw` check constraint                |
| Cells per read window        | 250,000                         | `MAX_WINDOW_AREA` in `workbooks.routes.ts`                        |
| Cells per evaluated range    | 2,000,000                       | `MAX_RANGE_CELLS`, returns `#NUM!`                                |
| Sheet bounds                 | 1,048,576 rows x 16,384 columns | `MAX_ROWS`, `MAX_COLS`, `cells` check constraints                 |
| Request body                 | 4 MiB                           | `BODY_LIMIT_BYTES`                                                |
| API instances                | 1                               | In-memory throttle counters (GC-008) and per-process engine cache |
